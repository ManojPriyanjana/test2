# Simple POS System

This repository contains a minimal point-of-sale (POS) system for a retail shop.

## Features
- Maintain an inventory of products
- Add items to a cart by scanning product IDs
- Calculate totals and checkout
- Interactive command-line interface

## Usage
Run the application:

```bash
python pos_system.py
```

## Tests
Execute unit tests using:

```bash
python -m unittest
```
